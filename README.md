# АТЛАС — рабочее пространство ВПИ

Автономный редактор карты с headless-ядром, библиотекой UI и расширениями.

- `work/atlas/` — исходники, тесты, оригинал карты и документация API.
- `outputs/workspace.html` — готовая страница с текущей партией.
- `outputs/` — автономные страницы, сохранения и согласованные макеты.
- `AGENTS.md` и `work/atlas/AGENTS.md` — правила дальнейшей работы.

## Сборка и проверки

Из корня репозитория:

```sh
python3 work/atlas/build.py
cd work/atlas
node --test tests/*.test.cjs
```

Сборка создаёт `work/atlas/dist/index.html`. При обновлении готовой страницы
партии необходимо сохранять её встроенные данные и ключ автосохранения —
подробности в `work/atlas/AGENTS.md`.

## Git

Репозиторий находится в корне этой рабочей папки; основная ветка — `main`.
Сохранены прежние коммиты исходников. Исходники, правила, готовые HTML, JSON
и изображения находятся под контролем версий. Временные партии, резервные
копии в `work/`, QA-страницы и сборочные архивы исключены через `.gitignore`.

Удалённый репозиторий не настроен; история хранится локально.
