# АТЛАС — редактор военно-политической игры

Откройте `dist/index.html` в современном браузере. Файл содержит карту, индекс,
стили и весь JavaScript: установка, сборка и веб-сервер для игры не требуются.
Для публикации на обычном статическом хостинге достаточно этого же файла.

## Что работает

- Перемещение карты мышью, масштаб колесом, кнопками и двумя пальцами.
- Постоянные ID провинций, подсветка, события наведения и клика.
- Создание, переименование, смена цвета и удаление наций.
- Назначение отдельных провинций нациям и освобождение территорий.
- Создание регионов как групп провинций; назначение целого региона одной нации.
- Имена провинций, отмена и повтор до 100 действий.
- Автосохранение в IndexedDB, экспорт/импорт редактируемой партии в JSON.
- Экспорт PNG в исходных 5616 × 3000 пикселей, без панелей и подсветки.
- Экспорт автономного HTML со всей текущей партией для передачи друзьям.
- Загрузка новых PNG/JPEG/WebP с выбором цвета суши и допуска.

Каждый игрок редактирует свою копию. Сетевой синхронизации и общего состояния
между игроками здесь нет. Для обмена ходами передавайте JSON или HTML.

## Разделение ядра и надстроек

| Файл | Ответственность |
| --- | --- |
| `core.js` | Чистая модель, singleton, индекс пикселей, провинции, нации, регионы, события и транзакции. Не использует DOM или Canvas. |
| `viewer.js` | Базовый Canvas, камера, жесты, определение провинции под курсором, подсветка выбора и события. Не знает про раскраску владельцев. |
| `territory-painter.js` | Съёмная надстройка: собственный прозрачный Canvas поверх карты, кисть, назначение территорий нациям, раскраска групп и PNG. |
| `app.js` | Сборка приложения, интерфейс редактора наций/регионов, диалоги, автосохранение, файловые операции и запуск индексатора в Web Worker. |
| `page.html`, `style.css` | Разметка и стили. |
| `build.py` | Упаковывает всё в один автономный HTML без npm-зависимостей. |
| `default-project.json` | Предварительно подготовленная исходная карта с индексом. |

### Singleton

В браузере доступен `window.MapIndex`. Это единственный экземпляр
`AtlasCore.MapRegistry.getInstance()`. Другой экземпляр создать нельзя.

```js
const index = window.MapIndex;
index.nations;   // Map<string, {id, name, color}>
index.regions;   // Map<string, {id, name, metadata}>
index.provinces; // Map<number, {id, area, bbox, anchor, name, nationId, regionId, metadata}>
index.labels;   // Uint16Array / Uint32Array: province ID на каждый пиксель; 0 = море/граница

const province = index.at(2791, 1300); // Координаты исходного изображения
const provinceById = index.getProvince(2670);

index.setNation({id: 'my-nation', name: 'Моя нация', color: '#517eaa'});
index.setRegion({id: 'north', name: 'Север'});
index.setProvince(2670, {regionId: 'north', name: 'Северная провинция'});
index.getRegionProvinces('north');
```

Для изменений используйте методы: прямое изменение содержимого Map не создаёт
событий, истории или автосохранения. `metadata` предназначено для расширения
модели; в текущем интерфейсе оно не редактируется.

### События и обратные вызовы

```js
const unsubscribe = MapIndex.on('province:hover', ({id, province, x, y}) => {
  // id и province = null при уходе с провинции, включая уход на море.
  console.log(id, province);
});
MapIndex.on('province:click', ({id, province, x, y, originalEvent}) => {
  // x, y — координаты исходного изображения, независимо от масштаба.
});
MapIndex.on('selection:change', ({id, province}) => {});
MapIndex.on('change', ({label, before, after}) => {});
MapIndex.on('map:loaded', ({index}) => {});
unsubscribe();

// Hover/click также дублируются как CustomEvent на window:
window.addEventListener('province:click', event => console.log(event.detail.id));
```

Наведение публикуется при смене провинции. Перетаскивание и жест масштаба не
создают событие клика. Точный клик по границе или морю возвращает `null`.

### Надстройка раскраски

```js
// Основной интерфейс экспортирует готовые экземпляры:
const {index, viewer, painter} = window.Atlas;
painter.setActiveNation('my-nation');
painter.paintProvince(2670, 'my-nation');
painter.paintRegion('north', 'my-nation');
painter.paintProvince(2670, null); // Освободить провинцию

index.undo();
index.redo();

// Независимый старт в своём интерфейсе:
const model = AtlasCore.MapRegistry.getInstance();
const view = new AtlasView.MapViewer(model);
// view.load(baseImage); model.load(project, decodedPixelIndex);
// Вызов конструктора расширения необязателен:
const extension = new AtlasPlugins.TerritoryPainter(model, view);
extension.destroy(); // Удаляет слой раскраски и его обработчики; ядро и камера работают.
```

Код `core.js` и `viewer.js` не импортирует `TerritoryPainter`. Данные владельцев
находятся в модели, а их визуализация и поведение кисти полностью принадлежат
расширению. Экспорт PNG собирает базовый Canvas и слой расширения отдельно.

`MapIndex.transaction('Название действия', () => { ... })` объединяет изменения
в один шаг отмены. Ошибка внутри транзакции откатывает все её изменения.

## Индексация и формат

В исходнике обнаружено 4587 отдельных областей суши. Четырёхсвязные компоненты
точного серого цвета `#808080` получают последовательные ID в порядке обхода
изображения сверху вниз. Каждый из 5 359 221 пикселя суши отнесён ровно к одной
провинции; острова и Антарктида также входят в индекс. Географических названий
в исходнике нет, поэтому они не выдумываются.

В PNG индекса ID закодирован как `R + G*256 + B*65536`. `bbox` хранится как
`[x, y, width, height]`, `anchor` — пиксель внутри соответствующей провинции.
Индекс не меняется от раскраски и при обмене партией остаётся прежним.

`region` — пользовательская группа нескольких провинций. Одна провинция
может входить в один регион; владелец задаётся на уровне провинции. Назначение
региона нации — транзакция назначения всех входящих в него провинций.

Новые карты индексируются локально в Web Worker. Сервер обработки для этой
версии не нужен. Для общего серверного индекса можно сохранить тот же формат
проекта и загрузить результат через `Atlas.loadProject(project)`.

Автоматический разбор использует цвет и замкнутые границы, а не географическое
распознавание. Разрыв границы объединит области; отдельные несвязанные острова
получат разные ID. Для надёжного результата предпочтителен PNG без сглаживания.
JPEG поддерживается, но артефакты сжатия могут ухудшить разбиение.

## Сборка и проверки

```sh
python3 build.py
node core.test.cjs
# Необязательная повторная подготовка исходной карты требует Pillow, NumPy, SciPy:
python3 preprocess.py '/путь/к/карте.png'
python3 build.py
```

Проверены в браузере: создание нации и региона; назначение двух провинций
одной группе; назначение группы другой нации; атомарная отмена и повтор;
hover/click с ID; экспорт PNG, JSON и HTML; загрузка новой карты и восстановление
после перезагрузки. PNG дополнительно проверен по размерам и цветам пикселей.
Открытие самого файла через `file://` автоматическим браузером недоступно из-за
его политики URL; автономность сборки обеспечена отсутствием внешних ресурсов.
