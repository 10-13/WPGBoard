БЫСТРЫЙ СТАРТ

Мир начинается с карты.

01

Выберите нацию

Нажмите на нацию слева, затем на провинцию. Для просмотра без закрашивания включите «Выбрать».

02

Исследуйте территории

Тяните карту для перемещения, вращайте колесо для масштаба. На сенсорном экране используйте два пальца для масштаба.

03

Сохраните и поделитесь

PNG — готовая картинка. JSON — редактируемая партия. «HTML для друзей» — карта и редактор в одном файле.

Каждый игрок работает со своей копией. Совместной синхронизации в этой версии нет. Номера провинций постоянны в пределах одной карты. Границы и отдельные острова определяются по исходному изображению.
