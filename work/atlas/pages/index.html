WPGBoard — карты для ВПИ

Каждая карта работает в браузере и доступна одним автономным HTML.

Игра сохраняется в вашем браузере. Для обмена партиями используйте меню «Файл».

JSON содержит карту, метаданные и историю действий. Его можно открыть в редакторе через «Файл».
